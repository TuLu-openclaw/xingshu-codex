# memory —— 自己的提示词 / 记忆

把要注入的提示词正文粘进本目录下的 `.md` 文件即可。

## 文件约定

| 文件 | 用途 |
|---|---|
| `星枢记忆.md` | **全局主提示词**。安装任一目标时默认用它（79707 字符的完整版） |
| `豆包破甲.md` | 豆包专用**精简版**。豆包全局记忆接口上限 12000 字符，超限会返回 `params invalid` |
| `WorkBuddy破甲.md` | WorkBuddy 专用**精简版**。它的 memoryBlock 上限 10000 字符 |

规则：

- 主提示词固定优先用 `星枢记忆.md`；它不存在时才取本目录下第一个非空 `.md`。
- `豆包破甲.md` / `WorkBuddy破甲.md` 是**目标专属**，不会被当成全局提示词。
- 安装豆包 / WorkBuddy 时，若完整版超限，脚本会自动改用对应的精简版；仍超限则直接失败并提示（不会写入半成品）。
- 两个精简版可以自己改，只要不超过各自上限：豆包 12000、WorkBuddy 10000（字符数，中文按 1 个算）。
- 本目录随打包进安装包（`resources/memory/`），打包后再改文件不会生效。
- 卸载走 `install*.ps1 -Uninstall`，本目录里的文件不会被改动。
